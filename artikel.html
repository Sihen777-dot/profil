Cara Membuat Form di Index HTML

Sep 2026 · Panduan praktis untuk pemula

Form adalah bagian penting di website, misalnya untuk kontak, login, atau pendaftaran. Di bawah ini penjelasan lengkap cara membuat form sederhana langsung di file index.html.

1. Buat struktur form dasar

Gunakan tag <form> sebagai pembungkus. Di dalamnya letakkan label, input, dan tombol kirim.

2. Tambahkan input yang dibutuhkan

Contoh input yang sering dipakai:

  • <input type="text"> → untuk nama
  • <input type="email"> → untuk email
  • <textarea> → untuk pesan panjang
  • <button type="submit"> → tombol kirim

3. Contoh kode lengkap

<form action="#" method="post">
  <div>
    <label for="nama">Nama</label>
    <input type="text" id="nama" name="nama" required placeholder="Nama lengkap">
  </div>

  <div>
    <label for="email">Email</label>
    <input type="email" id="email" name="email" required placeholder="email@contoh.com">
  </div>

  <div>
    <label for="pesan">Pesan</label>
    <textarea id="pesan" name="pesan" rows="4" required placeholder="Tulis pesan..."></textarea>
  </div>

  <button type="submit">Kirim Pesan</button>
</form>

4. Penjelasan atribut penting

  • required — wajib diisi; browser akan menolak jika kosong
  • id & for — menghubungkan label dengan input (klik label = fokus ke input)
  • name — nama data yang dikirim saat form disubmit
  • placeholder — teks petunjuk di dalam kotak input
  • type="email" — otomatis cek format email

5. Cara pembuatan (langkah demi langkah)

  1. Buka file index.html di VS Code atau editor lain.
  2. Di bagian yang diinginkan (misalnya section Kontak), tulis tag <form>...</form>.
  3. Isi form dengan label + input sesuai kebutuhan (nama, email, pesan).
  4. Tambahkan atribut required agar field wajib diisi.
  5. Buat tombol dengan <button type="submit">.
  6. Simpan file, lalu buka di browser untuk menguji form.
  7. (Opsional) Tambahkan CSS agar form rapi: lebar 100%, padding, margin antar elemen.
  8. (Opsional) Tambahkan JavaScript untuk validasi lebih lanjut atau menampilkan pesan sukses.

6. Tips tambahan

Form di portfolio ini sudah menerapkan cara di atas. Setelah form dibuat, pastikan tampilan responsive di HP dan desktop. Untuk mengirim data sungguhan (ke email/server) biasanya butuh backend (PHP, Node.js, dll) atau layanan seperti Formspree.
