Cara Membuat Tombol di HTML

Sep 2026 · Panduan praktis untuk pemula

Tombol (button) dipakai untuk aksi seperti kirim form, buka halaman, atau menjalankan JavaScript. Di bawah ini penjelasan lengkap cara membuat tombol di HTML.

1. Cara paling sederhana

Gunakan tag <button>:

<button>Klik Saya</button>

2. Jenis type tombol

  • type="button" — tombol biasa (tidak submit form)
  • type="submit" — mengirim data form
  • type="reset" — mengosongkan form
<button type="button">Tombol Biasa</button>
<button type="submit">Kirim</button>
<button type="reset">Reset</button>

3. Tombol dengan link (buka halaman lain)

Bisa pakai tag <a> yang diberi class tombol, atau bungkus button di dalam link:

<a href="kontak.html" class="btn">Hubungi Saya</a>

<!-- atau -->
<a href="https://wa.me/6283166181513">
  <button type="button">Chat WhatsApp</button>
</a>

4. Contoh kode lengkap + CSS sederhana

<!-- HTML -->
<button type="button" class="btn-primary">Kirim Pesan</button>

<!-- CSS -->
<style>
.btn-primary {
  background-color: #2563eb;
  color: white;
  border: none;
  padding: 10px 20px;
  border-radius: 8px;
  font-size: 1rem;
  cursor: pointer;
}
.btn-primary:hover {
  background-color: #1d4ed8;
}
</style>

5. Langkah pembuatan

  1. Buka file index.html di editor (VS Code).
  2. Tulis tag <button>...</button> di tempat yang diinginkan.
  3. Tambahkan atribut type sesuai kebutuhan (button / submit).
  4. Beri class (misalnya btn-primary) agar mudah di-style.
  5. Tulis CSS: warna, padding, border-radius, dan efek hover.
  6. Simpan, lalu buka di browser untuk melihat hasilnya.

6. Tips

  • Gunakan cursor: pointer agar mouse berubah saat diarahkan ke tombol.
  • Tambahkan :hover supaya ada feedback visual saat diklik/diarahkan.
  • Untuk aksesibilitas, pastikan teks tombol jelas (bukan hanya ikon tanpa label).
  • Di portfolio ini, tombol "Hubungi Saya" dan "Lihat Karya" memakai cara di atas.
