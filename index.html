Cara Membuat Form di Index HTML

Berikut panduan lengkap dan jelas cara membuat form kontak sederhana di file index.html.

1. Buat struktur form dasar

Gunakan tag <form> sebagai pembungkus. Di dalamnya letakkan label, input, dan tombol.

2. Tambahkan input yang dibutuhkan

Contoh input yang umum dipakai:

  • <input type="text"> → untuk nama
  • <input type="email"> → untuk email
  • <textarea> → untuk pesan panjang
  • <button type="submit"> → tombol kirim

3. Contoh kode lengkap

<form action="#" method="post">
  <div>
    <label for="nama">Nama</label>
    <input type="text" id="nama" name="nama" required placeholder="Nama lengkap">
  </div>

  <div>
    <label for="email">Email</label>
    <input type="email" id="email" name="email" required placeholder="email@contoh.com">
  </div>

  <div>
    <label for="pesan">Pesan</label>
    <textarea id="pesan" name="pesan" rows="4" required placeholder="Tulis pesan..."></textarea>
  </div>

  <button type="submit">Kirim Pesan</button>
</form>

4. Penjelasan atribut penting

  • required → wajib diisi, browser akan menolak jika kosong
  • id & for → menghubungkan label dengan input (klik label = fokus ke input)
  • name → nama data yang dikirim saat form disubmit
  • placeholder → teks petunjuk di dalam kotak input
  • type="email" → otomatis cek format email

5. Tips tambahan

Setelah form dibuat, tambahkan CSS agar tampilan rapi (lebar input 100%, jarak antar elemen, dll). Untuk validasi lebih lanjut bisa pakai JavaScript. Form di portfolio ini sudah menerapkan cara di atas.
